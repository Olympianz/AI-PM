# Agent Loop：一次任务从输入到完成

Agent Loop 是 Agent 执行一次任务的循环骨架：感知（Perceive）→ 规划（Plan）→ 行动（Act）→ 观察（Observe），循环往复直到任务完成或达到终止条件。

感知阶段把用户输入与上下文（Memory、工具返回结果）整理成模型可处理的状态；规划阶段由模型决定下一步动作或拆分子任务；行动阶段调用 Tool Use 执行（如搜索、读写文件、调用 API）；观察阶段把执行结果反馈回上下文，进入下一轮。

关键产品含义：Loop 的长度与失败恢复能力直接决定用户体验。没有工具回退和重试的产品，遇到一次工具报错就可能让任务失败；而设计良好的 Agent 会把失败转成可观察的中间状态，让用户知道进展。

给 PM 的三个检查点：1）每个行动是否都有可观测状态；2）失败时是否有兜底与重试；3）长 Loop 的成本（Token 与延迟）是否可控。
