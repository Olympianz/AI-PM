Agent 深入价值衡量指标体系

指标体系设计A/B 与灰度测试

通勤版摘要

**场景**：Agent 类产品上线后，需要证明它真的在更多场景更深地帮到了用户。\n**核心要点**：北极星指标选「任务成功率」与「单任务节省时间」，并配护栏指标（错误率、投诉率、成本）；过程指标（对话轮数、调用次数）不能当结果。\n**关键取舍**：短期行为指标 vs 长期价值指标；定量（A/B、留存）与定性（访谈、任务日记）结合；样本量与显著性决定结论可信度。\n**延伸思考**：不同场景的 Agent 价值不可直接相加，需要按任务类型分层衡量。

面试问题

如何衡量「Agent 是否真正深入帮助了用户」？请给出指标体系与验证方法。

答题提示

  • 任务完成率
  • 留存
  • A/B
  • 样本量
  • 定性
